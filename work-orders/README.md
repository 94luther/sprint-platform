# Work orders: one per AI seat
The owner pays for premium on each of these services. Each file in this folder
is a complete, self-contained brief for one of them, so a month of
subscriptions does maximum real work on this project.

How to use: open the service, paste the repo URL plus the matching brief
(or just paste the brief text), and let it work. Results come back as answers
to paste into issues or pull requests, or as code to drop into the tree.

- KIMI.md, for Kimi (K3, agentic coding and deep research): the biggest build
  jobs plus a deep research mandate.
- CODEX.md, for Codex in ChatGPT (repo-connected coding agent): pull-request
  sized engineering tasks with acceptance criteria.
- GEMINI.md, for Gemini (3.1 Pro): the creative director countersign on THE
  PULSE plus the standing design review.
- CHATGPT.md, for ChatGPT (deep thinking): the arbiter verdicts still owed.

Ground rules for every seat: the fidelity rules in AI-REVIEW-BRIEF.md are non
negotiable, findings go through the ledger statuses (open, applied, verified,
overturned), and every brief ends with the standing question about what we are
overlooking.
